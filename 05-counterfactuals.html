La plausibilidad se aproxima mediante ejemplos reales: se elige la observación más cercana del clúster objetivo, no necesariamente una transformación biológicamente posible. El criterio de una variable busca el menor desplazamiento L2 entre las cuatro opciones; puede no existir una solución.

Variables no modificables. En aplicaciones reales, algunas características no se pueden cambiar (por ejemplo, la fecha de nacimiento o los datos históricos) o no deberían modificarse por razones éticas, legales o prácticas. Conviene imponer restricciones de accionabilidad antes de buscar el contrafactual, y aceptar que algunas transiciones pueden ser inviables. Una transición de clúster no demuestra un cambio de especie ni una relación causal.
